# Curious Cat Learning · החתול הסקרן

**למידה מתוך סקרנות**

A Windows learning app in Hebrew that uses Codex to turn school materials into exams, quizzes, and guided practice, with feedback and student progress tracking. The interface supports Hebrew and right-to-left text.

This repository contains application source, automated tests, UI artwork, JSON schemas, and the licensed PDFium runtime. It does **not** include school materials, generated exams, student records, interpreted-source caches, or local account configuration. These stay on your computer and are ignored by Git. Tests create synthetic fixtures in temporary folders.

To build on 64-bit Windows with .NET Framework 4.8, run `./build.ps1 -Test` in PowerShell. The executable is created locally as `Education2k.exe`. The app creates the `מבחנים` (exams) and `תלמידים` (students) folders as needed. The **הוסף מבחן חדש** wizard accepts a name, a general description, and learning files, then prepares shared exam 1 before adding the topic to the student list. Unfinished drafts remain private in the local `_drafts` folder for retry or resume. Exam generation and open-answer grading require an installed, signed-in Codex client; automated tests run without contacting Codex. PowerPoint/Word are needed to render Office documents with visuals; PDF and image inputs can be used instead.

The application version is recorded in `VERSION`, starting at `0.1.0` for the initial publication. Every upload requires explicit owner approval. Each approved publication increments only PATCH (`0.1.1`, then `0.1.2`, and so on); changing MAJOR or MINOR requires separate approval. Local edits, builds, and tests do not increment the version. See `AGENTS.md` for the publication policy and `Tools/bump-version.ps1` for the local version update helper.

Ready-to-run Windows packages are available on the repository's **Releases** page.
Extract the entire ZIP to a writable folder and run `Education2k.exe`; keep its
configuration, `Schemas` and `Native` folders alongside it. The package contains
no school materials, exams, student records or account credentials. The app
creates its local data folders when needed. See `CHANGELOG.md` for release notes.
The owner's command **שחרר ריליס** authorizes one version update, tested build,
privacy audit, Git publication and GitHub Release with a ZIP and SHA-256 checksum.

`VERSION_DATE` stores the version's update timestamp in `yyyy-MM-ddTHH:mm:sszzz` format, including its UTC offset. The build embeds the version, timestamp, product name, and slogan in the executable. A small fixed strip at the top shows the version, date, and time on all screens, including exam preparation. Launching or copying the app does not change this timestamp. The approved version update helper records publication time in the Asia/Jerusalem timezone. The connection status is displayed in the fixed bottom bar.

תוכנת Windows מקומית למבחנים ולתרגול בעברית. לפתיחה לוחצים פעמיים על `Education2k.exe` שבתיקיית הפרויקט. אין צורך בשרת או במפתח API. נדרשים Windows עם ‎.NET Framework 4.8, חיבור לאינטרנט ו־Codex שמחובר לחשבון ChatGPT בעל גישה מתאימה. בתפריט **פרטי החיבור** ניתן להתחבר ולבדוק את החיבור מחדש. הבדיקה כוללת תגובה אמיתית מהמודל; סימון התחברות בלבד אינו נחשב לחיבור זמין.

## שימוש

כפתור **צור מבחן PDF** זמין גם לפני כניסה כתלמיד. מזינים שם מבחן, כיתה ובית ספר, מוסיפים חומרי לימוד בגרירה או בבחירה מהמחשב ולוחצים **צור מבחן**. אפשר ליצור מבחנים נוספים ללא הגבלת כמות בתוכנה. מסך ההמתנה מציג קריאת מקורות, יצירת שאלות ועימוד ושמירת PDF, עם אפשרות ביטול. בעיות קריאה מטופלות באותו מסך החלטה של המבחנים הרגילים.

כל הקבצים לכל יצירה, כולל עותקי המקורות, הטיוטה, שאלות שנוצרו, מטמוני תמונות וה־PDF, נשמרים בתוך **מבחנים/מבחנים להדפסה**. כל יצירה שהושלמה מקבלת תיקייה נפרדת; טיוטות שלא הושלמו נשמרות בתת־התיקייה `_drafts` להמשך. סביבת ההדפסה אינה מופיעה כנושא לתלמידים ואינה משנה ציונים או התקדמות. ה־PDF כולל שאלות עם שורות לכתיבה וטבלאות למילוי, ואחריהן חלק פתרונות שמתחיל בעמוד חדש. בכל עמוד מופיעים לוגו החתול, קישור לחיץ לפרויקט והייחוס „נוצר עם Codex”. הייצוא אינו דורש Word, Python או מדפסת PDF מותקנת.

בסיום יש כפתורים לפתיחת הקובץ, **שמירת עותק / הורדה**, **הדפסה**, פתיחת התיקייה ויצירת מבחן נוסף. הקובץ המקורי נשאר בסביבת ההדפסה; שמירת עותק מאפשרת לבחור יעד במפורש. בחלון ההדפסה ברירת המחדל היא טווח עמודי השאלות בלבד, ואפשר לבחור את כל העמודים כדי לכלול גם את הפתרונות. הטווחים מוצגים גם במסך הסיום.

כפתור **הוסף מבחן חדש** זמין גם לפני הזנת שם תלמיד. באשף מזינים שם ותיאור כללי בלבד. התיאור נשמר אוטומטית בקובץ `_describe.txt`; אין צורך בשדות נפרדים לכיתה או לעמודים. בשלב הבא גוררים קבצים לתוכנה, בוחרים אותם בחלון Windows או פותחים את תיקיית הטיוטה ומעתיקים אליה קבצים. הרשימה מתעדכנת גם כאשר מוסיפים חומר דרך סייר הקבצים. הקבצים המקוריים אינם משתנים; שמות זהים עם תוכן שונה מקבלים סיומת מספרית. הסרה מהרשימה מעבירה את עותק הטיוטה לתיקייה פנימית שאינה נקראת כחומר לימוד.

במסך הסיכום לוחצים **סיום והוספת המבחן**. המערכת משתמשת בתהליך הקריאה והפענוח הרגיל, כולל מסך ההחלטה אם יש בעיות בחומר, ויוצרת את מבחן מספר 1. רק לאחר שמירה ואימות מוצלחים התיקייה עוברת ל־`מבחנים` והנושא זמין לתלמידים. ביטול או תקלה שומרים את הטיוטה, התיאור והקבצים בתיקיית `_drafts`, מחוץ לרשימת הנושאים; בפתיחה הבאה של האשף אפשר להמשיך. יש לגבות גם תיקייה זו אם רוצים להעביר טיוטות למחשב אחר. היא וחומריה מוחרגים מגיט. העזרה להוספה ידנית זמינה כקישור משני באשף.

במסך הכניסה מוצג במרכז, מעל שדות השם, החתול הקורא וממצמץ מההנפשה שאושרה. ההנפשה פועלת בלולאה שקטה כל עוד מסך הכניסה מוצג, ונעצרת במעבר למסך אחר. אפשר להזין את השם מיד. אם ההנפשות כבויות בהגדרות Windows מוצג הפריים הראשון. כל פריימי ההנפשה מוטמעים בקובץ התוכנה, ללא צורך בקובצי תמונה חיצוניים או בהתקנה נוספת. ה־GIF המאושר שמור ב־`Assets/LogoAnimation/cat-reading.gif`; המרה מחדש לפריימים נעשית באמצעות `Tools/prepare-logo-animation.py` עם Pillow, ואינה נדרשת להפעלת התוכנה או לקימפול רגיל.

1. מזינים שם פרטי ושם משפחה. אותו שם פותח את אותה תיקיית תלמיד גם בפעמים הבאות.
2. בוחרים מבחנים, נושא, ואז **בוחן**, **מבחן אמיתי** או **מבחן עם עזרה**. מצב למידה מציג „התוכנה בבניה”.
3. במבחן אמיתי אפשר לעבור בין שאלות ולשנות תשובות עד לסיום. התוכנה מציגה זמן שחלף. לאחר 50 דקות מופיעה הודעה שקטה בפינה למשך דקה. אין צליל, ספירה לאחור או הגשה אוטומטית.
4. במבחן עם עזרה הרמז הלימודי מוצג אוטומטית בכל שאלה, לפני שדות התשובה וללא לחיצה. לוחצים **בדיקת התשובה** לקבלת משוב ומנסים שוב עד לתשובה נכונה. אין ציון ואין מגבלת זמן. אפשר לשמור ולחזור מאוחר יותר. פתיחת ההסבר האוטומטית כשלעצמה אינה מסמנת נושא כחלש; המשוב מתחשב בתשובות ובניסיונות.
5. חשיפת רמז במבחן אמיתי או בבוחן מכפילה את הניקוד המתקבל על השאלה ב־0.5. הרמז הוא קטע לימודי של כמה משפטים, עם הסבר ודוגמאות שמכילים כמעט את התשובה המלאה. החשיפה נשמרת ולא ניתן לבטל אותה באמצעות יציאה או מעבר בין שאלות. במצב עם עזרה הרמז נשמר כחלק מנתוני התרגול, ללא ציון.
6. בסיום מופיע משוב מקוצר: לכל שאלה מוצג מצב ההבנה. תשובה נכונה מקבלת „כל הכבוד!” בלבד; אם הניקוד ירד רק בגלל רמז, הדבר נכתב במפורש. בתשובה שדורשת תיקון מוצגים תשובת התלמיד, התשובה המלאה והסבר ממוקד על מה שחסר או לא מדויק. בשאלה עם סעיפים מוצגים בהרחבה רק הסעיפים הבעייתיים. את נוסח השאלה והמקורות ניתן לפתוח לפי הצורך. דוחות ישנים מותאמים פעם אחת דרך Codex ונשמרים לשימוש חוזר, בלי לשנות את הציון, התשובות או המשוב המקורי. אם ההתאמה אינה זמינה, הדוח נשאר קריא בנוסח הקיים בתוך התצוגה המקוצרת. לאחר **המשך** אפשר לחזור למסך הראשי, לגשת למבחן נוסף או לצאת.

**בוחן** הוא אותה מתכונת עצמאית בהיקף קטן: מחצית ממספר השאלות של המבחן המלא, בעיגול כלפי מעלה, ו־35 דקות מומלצות. כך למשל מבחן בן 14 שאלות הופך לבוחן בן 7 שאלות. נשמר מגוון סוגי השאלות הקיים במבחן. הניקוד מנורמל ל־100, ובדקה ה־25 מופיעה תזכורת שקטה למשך דקה. אין הגשה אוטומטית או ספירה לאחור. הבחנים נשמרים בתיקיית הנושא בשמות `_quiz_0001.json` וכן הלאה, עם מספור והתקדמות נפרדים מהמבחנים המלאים. מעבר בבוחן מעל 80 פותח את הבוחן הבא ואינו מדלג על מבחן מלא.

באותו מספר גרסה, המבחן הרגיל והמבחן עם עזרה משתמשים באותן שאלות בדיוק. בוחן מספר 1 משתמש במחצית נבחרת של שאלות מבחן מספר 1, וכן הלאה; הוא אינו מייצר שאלות חדשות. המספור של הבחנים נפרד, ולכן תלמיד עשוי להיות בבוחן 1 ובמבחן מלא 2.

שאלות פתוחות מוצגות במבנה נגיש: קודם השאלה והעובדות, ולאחר מכן סעיפים א, ב, ג וכן הלאה, עם שדה תשובה עצמאי לכל סעיף. משימה הדורשת מידע מקביל על מספר פריטים מוצגת בטבלה. השמירה והבדיקה כוללות את כל הסעיפים, וגם דוח הסיום מפרט את התשובות לפי סעיפים.

## חומרי לימוד ומבחנים משותפים

כפתור **כיצד להוסיף מבחן חדש** נמצא בין **המסך הראשי** לבין אזור החיבור. הוא פותח מדריך בעברית עם שלבים, איור של מבנה התיקיות, דוגמה לקובץ התיאור וכפתור לפתיחת תיקיית **מבחנים** במחשב הזה. אפשר לפתוח את המדריך גם לפני הזנת שם ולחזור למסך הקודם.

כל תיקייה ישירה תחת **מבחנים** היא נושא. בתוכה שמים `_describe.txt` ובו הכיתה, נושא המבחן והיקף החומר, ואת קובצי חומר הלימוד. נקראים טקסט (UTF-8, עברית Windows או UTF-16), Markdown, DOCX, PPTX, PDF ותמונות. קורא PDF מקומי מסוג PDFium מחלץ טקסט ומכין תמונה חדה של כל עמוד; גם סריקות ללא שכבת טקסט עוברות פענוח חזותי דרך Codex הקיים, ללא מפתח API. במצגת נקראים הטקסט והערות המרצה לפי סדר השקופיות, ותצוגת כל השקופיות נמסרת ל־Codex לפענוח התמונות, המפות והתרשימים. לייצוא המצגות נדרשת התקנת PowerPoint, ולמסמכי Word עם תוכן חזותי נדרש Word. אם אינם מותקנים אפשר לצרף ייצוא PDF במקום. כשל בייצוא מוצג כמגבלה, ואינו נחשב לקריאה מלאה.

הפענוח כללי לכל תיקיות הנושאים וקבצים חדשים: אין תלות בשם המבחן, במקצוע או במספר שקופית. כאשר שקופית נשארת חלקית, המערכת מנסה גם את תמונות המקור המוטמעות בה, למשל כדי לקרוא מקרא שכוסה בשכבת עיצוב. פרטים שנותרו מטושטשים או חסרים ממשיכים להופיע בדוח עם החלטת המשתמש. עמודים מוזכרים בספר שאינו מצורף אינם נחשבים לחומר שנקרא.

תמונות העמודים, שיוך המקורות והפענוח נשמרים בתיקיית `_materials` שבתוך תיקיית הנושא, לפי טביעת תוכן הקובץ וגרסת הקורא. זהו מטמון חומרי לימוד, ולא יומן פעילות. קובץ שלא השתנה אינו נשלח שוב לפענוח. שינוי בקובץ או פגיעה בתמונת מטמון גורמים לבדיקה או הכנה מחדש. שאלות קיימות בחומרי בית הספר יכולות לשמש בסיס למבחן. תמונות מתאימות יכולות להופיע בשאלה, עם כיתוב ניטרלי וכפתור הגדלה, ונשמרות גם בבוחן. אין לבחור תמונת פתרון או תמונה שלא פוענחה היטב. יש לגבות ולהעתיק את `_materials` יחד עם המבחנים ששייכים אליהן.

כאשר בדיקת המקורות מזהה בעיה לפני יצירת מבחן, יש שלוש אפשרויות: לחזור למסך הראשי, ליצור בכל זאת מהחומר שנקרא, או **צור את המבחן ללא החומר הבעייתי**. האפשרות השלישית מציגה מה יוחרג. אם הקריאה מאפשרת לזהות את העמודים או השקופיות הבעייתיים, רק הם ותמונותיהם מוחרגים; אם אין הפרדה אמינה, הקובץ כולו מוחרג. חומר של מקור שלא נקרא, פענוחו, תמונותיו ושאלות קודמות המבוססות עליו אינם נמסרים ליצירה, והחיפוש ברשת כבוי. כל שאלה חייבת לצטט מזהה של יחידת מקור מאושרת. כשלא נשאר חומר קריא, לא נוצרת בקשת שאלות ולא נשמר מבחן.

רשימת ההחרגות נשמרת עם המבחן והבוחן ומוצגת בפתיחה, בסיכום ובהישגים. הציון והמוכנות מתייחסים לחומר שנכלל בלבד. מבחן שכבר נשמר ממשיך עם היקף המקורות שלו; לא מוצעת עריכת היקף שמשנה בדיעבד את השאלות והישגי תלמידים. אם בעיה חדשה מתגלה במהלך יצירה ובוחרים להחריג, הטיוטה נזרקת ושאלות חדשות נוצרות מהחומר שנשאר, לפני שמירה.

לפני יצירת שאלות מתבצעת בדיקת מקורות נפרדת באמצעות Codex. לכל קובץ מתקבל הסבר בעברית מהצ׳אט על מה נקרא, מה לא נקרא, השפעת המגבלה ומה אפשר לעשות לתיקון. כשל חילוץ, קובץ נעול או פגום, טקסט שנחתך עקב גודלו ותוכן חזותי שלא פוענח אינם נחשבים לקריאה מלאה. גם תיאור חסר או תיקייה ללא חומר מחייבים דיווח. הדוח נשמר ב־`_material_review.json` וממוחזר רק כשהחומרים, גרסת הקורא ותוצאות הפענוח תואמים.

כאשר יש בעיה מוצג מסך החלטה עם **צור את המבחן בכל זאת** ו־**חזור למסך הראשי**. חזרה או סגירת החלון עוצרות לפני יצירת השאלות ולפני שמירת מבחן או ניסיון תלמיד. בלי אישור מפורש אין המשך אוטומטי. אם התגלתה בעיה חדשה בזמן הכנת השאלות, נדרש אישור נוסף לפני שמירה. שינוי בחומרים במהלך הבדיקה או ההחלטה מבטל את האישור. הדוח נשמר גם במבחן ובבוחן, ולכן המגבלה מוצגת גם כשמשתמשים בגרסה שמורה.

מבחנים ישנים שמציינים במבוא שמקור לא נקרא מקבלים דוח הסבר נפרד ב־`_exam_0001.material-review.json` וכדומה, בלי לשנות את השאלות או ההישגים. החלון מבהיר שזה מבחן שמור שנוצר עם חומר חסר. קריאה משופרת של המקור כיום אינה מתקנת בדיעבד את שאלות המבחן הישן. כדי להכין מחדש מבחן מתוך החומר המתוקן בלי לפגוע בפעילויות קיימות, אפשר ליצור תיקיית נושא חדשה ולהעתיק אליה את המקורות וקובץ התיאור בלבד.

Codex רשאי לחפש חומר משלים ברשת ובאתרי משרד החינוך במסגרת הנושאים שהוגדרו. שאלות המבחן שומרות הפניות למקורות. דף מטרים שמפנה לספר שאינו מצורף אינו נחשב לעותק של הספר; אין הבטחה שהמודל יקרא עמודים שאינם נגישים.

המבחנים נשמרים בתיקיית הנושא בשמות `_exam_0001.json`, `_exam_0002.json` וכן הלאה. כל גרסה כוללת שאלות, תשובות, מחוונים ורמזים. תלמיד חדש מתחיל בגרסה 1. מעבר במבחן אמיתי בציון **גבוה מ־80** מקדם את התלמיד לגרסה הבאה. ציון 80 בדיוק ותרגול עם עזרה אינם מקדמים גרסה. אם הגרסה הבאה כבר קיימת משתמשים בה; אחרת יוצרים ושומרים אותה עבור כולם. נעילה בלעדית מונעת כתיבה מקבילה של שתי גרסאות לאותו מספר.

אין לשנות ידנית מבחן שכבר נעשה בו שימוש, משום שדוחות התלמידים מפנים לגרסה המשותפת. שדרוג התצוגה לגרסה 2 מוסיף סעיפים וקטעי לימוד, ושומר את מזהי השאלות, הנוסח המקורי, המחוון והניקוד. לפניו נוצר עותק גיבוי בסיומת `.before-presentation-v2`. תשובות ישנות נשמרות וניתנות לצפייה בנוסח המקורי; ניסיונות חדשים משתמשים במבנה הסעיפים. שדרוג אוטומטי של מבחן ישן דורש חיבור פעיל ל־Codex רק בפעם הראשונה. כשמשנים חומרי לימוד, מבחנים קיימים נשמרים והממשק מודיע שהמקור השתנה. יצירת גרסאות חדשות מתבססת על החומר המעודכן. קבצים ששמם מתחיל בקו תחתון נחשבים לקובצי מערכת ואינם חומר לימוד.

## נתוני תלמידים

התיקייה **תלמידים / שם פרטי שם משפחה** מכילה פרופיל `_student.json` ותיקיית **נסיונות**. כל ניסיון שומר תשובות, שימוש ברמז, משוב, ניסיונות חוזרים, מועד התחלה וסיום וציון במבחן אמיתי. גם מבחן שטרם הסתיים נשמר, והכניסה הבאה לאותו נושא ומצב ממשיכה אותו. שמירה נעשית בקובץ זמני ובהחלפה אטומית, עם גיבוי `.bak` של השמירה הקודמת.

ההישגים מציגים היסטוריה, הצלחה בניסיון הראשון ללא רמז ומוכנות לפי המבחן העצמאי האחרון. זו הערכת ביצוע בחומר שנבחן, לא אבחון של כושר הלמידה. רצוי לגבות את תיקיות **מבחנים** ו־**תלמידים** יחד.

## החיבור ל־Codex

מסך ההמתנה מציג את החתול המונפש, שלבים המבוססים על הפעולות בפועל (קריאה, בדיקת מקורות, יצירת שאלות, בדיקה ושמירה), זמן שחלף ומועד עדכון הפעילות האחרון. שלבים שאינם נדרשים בגרסה שמורה מסומנים בהתאם. „מה קורה עכשיו? — פריוויו הפעילות” מציג יומן בעברית. העדכונים נשמרים בזיכרון בלבד, ללא קובצי יומן או כפתור פתיחת יומן, ונמחקים מהתצוגה בסיום הפעולה.

היישום קורא את זרם האירועים של `codex exec --json` תוך כדי העבודה. בפריוויו מוצגים רק אירועי מחזור הבקשה וסוגי פעולות בטוחים, וכן הודעות מזוהות על חסימת כלי בהרשאות או ניסיון חיבור מחדש. לא מוצגים פקודות גולמיות, פלט כלים, תוכן השאלות, תשובות, מחוונים או תוכן חשיבה. אנימציה אינה נחשבת לעדכון התקדמות: אם לא התקבל מידע חדש במשך דקה, המסך אומר זאת במפורש. אין אחוזים או זמני סיום משוערים שאינם ידועים.

חיווי השמירה מבדיל בין דוח מקורות, המבחן המלא ובוחן: שמירת דוח אינה מוצגת כשמירת המבחן, וביצירת בוחן שמירת מבחן המקור אינה מוצגת כשמירת הבוחן. המתנה לנעילה של תהליך אחר מדווחת לפני שנשלחת בקשת יצירה חדשה. אפשר לבטל בזמן ההמתנה. ההנפשה נעצרת כשהמסך מוסתר, ועדכונים מאוחרים מפעולה שבוטלה אינם עוברים לפעולה הבאה.

היישום מפעיל `codex exec` בתהליך נפרד, עם הרשאת קריאה בלבד ופלט JSON לפי סכמה. היישום עצמו מבצע את השמירה. ההתחברות נעשית באמצעות `codex login`; אין צורך לפתוח את חלון הצ׳אט או לכתוב בו הודעת חיבור. חשבון Codex ומגבלות השימוש שלו נדרשים ליצירה ולבדיקת שאלות פתוחות. בדיקת שאלות בחירה נעשית מקומית.

חומרי המקור ותשובות נשלחים ל־OpenAI לפי תנאי החשבון; שם התלמיד אינו נכלל בבקשות הבדיקה. מפתחות וסיסמאות אינם נשמרים בפרויקט. אם Codex אינו מזוהה אפשר להגדיר משתנה סביבה `EDUCATION2K_CODEX` לנתיב המלא של `codex.exe`.

## קימפול ובדיקות

הפרמטר `--preview-print` פותח מסך יצירת PDF בתיקיית בדיקה מבודדת תחת `Build`, עם מודל מדומה המסומן בממשק וללא פנייה ל־Codex. הפרמטר `--print-example` יוצר דוגמה סינתטית עם תרשים ושאלות משלושת הסוגים בתוך סביבת המבחנים להדפסה המקומית; הוא אינו קורא חומרי בית ספר או מידע על תלמידים. הבדיקות מכסות הפרדת שאלות ופתרונות, עברית מעורבת בנוסחאות, שורות תשובה וטבלאות, מקור ותמונות שנשארים בתוך סביבת ההדפסה, יצירות חוזרות באותו שם, אזהרות מקור, ביטול בזמן הכתיבה ומניעת שמירת PDF חלקי.

הפרמטר `--preview-feedback` פותח דוח סינתטי המציג תשובה נכונה, הפחתה עקב רמז, תשובה שגויה, תשובה ריקה ומשוב ממוקד על סעיף אחד מתוך כמה סעיפים. הוא אינו פונה ל־Codex ואינו קורא מידע על תלמידים אמיתיים. התאמת דוח ישן משתמשת בסכמה נפרדת, ללא שדות ניקוד. הבדיקות מוודאות שההתאמה אינה משנה ציונים, תשובות, בדיקות קודמות או תאריכים, וששיוך לסעיף לא מוכר נדחה בלי שינוי חלקי של הדוח.

הפרמטר `--preview-scroll` פותח מבחן סינתטי בחלון המינימלי, לבדיקת גלילה מעל טבלה רחבה ותאי תשובה. הנתונים נשמרים בתיקיית בדיקה נפרדת תחת `Build`, ללא פנייה ל־Codex. בדיקות הגלילה האוטומטיות בודקות מעבר מהשדה למסך בקצה העליון והתחתון, שמירת הגלילה בתוך תשובה ארוכה וגלילה אופקית עצמאית בטבלאות.

הפרמטר `--preview-new-exam` פותח את האשף בתיקיית בדיקה חדשה ומבודדת תחת `Build`, עם מודל מדומה המסומן במפורש בממשק. הוא אינו פונה ל־Codex ואינו מעתיק חומרי בית ספר או תלמידים אמיתיים. לבחירת קובץ סינתטי אפשר להשתמש ב־`Build/wizard-demo-material.txt`. הבדיקות האוטומטיות מכסות שמירת טיוטה וחזרה אליה, יבוא קבצים וכפילויות, כשל וביטול יצירה, שינוי חומר תוך כדי הכנה, מניעת דריסת נושא קיים, ופרסום מבחן 1 יחד עם תמונותיו רק לאחר השלמה.

הפרמטר `--test-live-progress` בודק זרם אירועים אמיתי של Codex עם בקשת בדיקה קצרה ושומר תוצאה ב־`Build/progress-live-test.txt`. הפרמטר `--preview-waiting` פותח את מסך ההמתנה על עותק נתונים ב־`Build/UiPreview2`, עם מודל מדומה שמסומן במפורש כתצוגת בדיקה. בדיקות ההתקדמות כוללות הפרדה בין קובצי ביניים למבחן, תצוגת עדכונים בזיכרון בלבד, ביטול המתנה לנעילה וסינון תוכן רגיש מהפריוויו.

הפרמטר `--review-materials` מפעיל בדיקת קריאה אמיתית באמצעות Codex ל־PDF ולכל שקופיות מצגת ההיסטוריה, כולל פענוח תמונות המקור כאשר שכבות מסתירות חלק ממפה, ושומר תוצאה ב־`Build/material-review-live.txt`. הוא אינו יוצר שאלות או משנה מבחן קיים. בדיקות ההחלטה האוטומטיות משתמשות במודל מדומה כדי לבדוק שאישור נדרש לפני יצירה ושמירה, בלי לצרוך מכסה. תצוגת הבדיקה `--preview-materials` מציגה את שלוש האפשרויות ואת רשימת ההחרגות על סמך קריאת חומרי ההיסטוריה. היא שומרת תוצאת בדיקה ב־`Build/history-exclusion-test.txt`, ואינה יוצרת מבחן או הישגים לתלמידים האמיתיים.

האיקון המאושר של החתול שקורא ספר נמצא ב־`Assets/app-icon.png`. בזמן הקימפול `Tools/build-icon.ps1` יוצר ממנו קובץ ICO שקוף בעשרה גדלים, מ־16 ועד 256 פיקסלים. האיקון מוטמע בקובץ התוכנה ובחלון, ואין צורך להעתיק את תיקיית `Assets` להפעלת התוכנה. אם קיצור שכבר הוצמד לשורת המשימות עדיין מציג את האיקון הישן, יש לבטל את ההצמדה ולהצמיד מחדש את `Education2k.exe` המעודכן.

בתיקיית הפרויקט מפעילים PowerShell:

```powershell
./build.ps1 -Test
```

הקימפול משתמש במהדר ‎.NET Framework שמגיע עם Windows, עם ספריית PDFium הכלולה בתיקיית `Native` (Windows x64). קוד המקור ב־`Source`, סכמות התשובות ב־`Schemas`. כדי להעביר למחשב אחר יש להעתיק את `Education2k.exe`, את `Education2k.exe.config`, את `Native`, את `Schemas` ואת שתי תיקיות הנתונים יחד. גם במחשב היעד נדרשת התקנת Codex והתחברות.

תוצאות הבדיקות נמצאות ב־`Build/tests.txt`. הבדיקות האוטומטיות פועלות בתיקייה זמנית ואינן מוסיפות הישגים לתלמידים. בדיקות חיבור אמיתיות זמינות באמצעות הפרמטרים `--check-connection`, `--generate-example`, `--grade-example` ו־`--test-updates`; הן משתמשות במכסת החשבון. בדיקת יצירת הדוגמה שומרת את מבחן 1 בנושא הראשון רק אם הוא עדיין אינו קיים. `--refresh-exams` משדרג מבחנים שמורים למבנה הסעיפים והרמזים החדש ויוצר את הבחנים המקבילים להם.
